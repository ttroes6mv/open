# どれみピアノ（2オクターブ版）

iPad の Safari でそのまま遊べる、ひらがなラベル付きのタッチピアノです。
**スマホ・タブレットを横向きに持って使う**前提のレイアウトです。
操作ボタンは画面の左端に縦一列（上下いっぱい）、その隣にキャラクター、いちばん右が鍵盤。
本体を倒すと **上からボタン → キャラクター → 鍵盤** の順に並びます。
文字（ボタンのラベルと どれみ の丸）はすべて90°左に回してあるので、
**本体を時計回りに倒す**と、ボタンが鍵盤の上に来て文字がまっすぐ読めます。
白鍵は左から右へ低い音→高い音、ひらがなのラベルは鍵盤の下（＝普通のピアノの配置）。
画面回転ロックが ON のままでも同じように使えます。
HTML 1ファイルだけ（`index.html`）で完結します。ピアノの録音データも Base64 で中に埋め込んであるので、
外部ファイルもライブラリもネット接続も不要です（約660KB）。

おまけで **リズムゲーム（`rhythm.html`）** も入っています。ピアノの「🎮 リズム」ボタンから遊べます。
→ [リズムゲームの説明](#リズムゲーム-リズムで-ポンrhythmhtml)

## できること

- **2オクターブ**（ど〜ど〜ど、白鍵15個）がデフォルト。ボタンで **1 / 2 / 3 オクターブ** に切り替え
- 「◀ ひくい / たかい ▶」で音域そのものを上下に移動（C1〜C8 の範囲）
- 白鍵は **ひらがな（ど れ み ふぁ そ ら し）+ にこにこ顔**、色は元のアプリと同じ配色。
  高いオクターブほど少し明るい色＋白いふちどりで見分けやすくしています
- 黒鍵あり（♯の音も鳴ります）
- 指を何本置いても同時に鳴ります（和音OK）。なぞるとグリッサンド
- がっき4種類：ピアノ / オルガン / ベル / マリンバ
- **ピアノは本物のピアノを録音した音（サンプリング）**。3半音おきに21音の MP3 を
  Base64 で HTML に埋め込んであり、外部ファイルもネット接続も不要です。
  間の音は最も近いデータを再生速度で±1半音ずらして作ります（ずれは実測±2セント以内）
- オルガン / ベル / マリンバは FM 合成（サイン波の周波数を別のサイン波で揺らす方式）
- 基準ピッチは A=442Hz
- **指を離しても音は最後まで鳴りきります**（オルガンだけは離すと止まります）
- **踊るキャラクター**：ボタンと鍵盤の間で常にダンスしています。鍵盤を押すとジャンプして
  笑顔になり、押した音の色に変わります（黒鍵はむらさき）。鍵盤の長さはその分だけ短くしました
- **おてほんモード**：「おてほん」ボタンで曲を選ぶと、次に押す鍵盤に★マークが出ます。
  マークを押すたびに次へ進むので、**マークを追いかけるだけで曲が最後まで弾けます**。
  最後まで行くと鍵盤が順番に光ってお祝いし、自動的に最初に戻ります。
  マーク以外の鍵盤も普通に音が鳴るので、自由に遊びながら練習できます。
  収録曲：**きらきらぼし / かえるのうた / ちょうちょ**（いずれも著作権の切れた民謡）
- **じぶんの きょく（録音）**：「ろくおん」ボタンを押してから鍵盤を弾くと、
  押した順番がそのまま記録され、**自分だけのお手本**になります。
  もう一度押すと停止。録音中はボタンに音数が表示されます。
  好きな曲を耳コピして登録できます。内容は端末に保存されるので次回もそのまま使えます
- なまえ表示：ひらがな / ABC（C4 など）/ なし
- **🎮 リズム ボタン**：リズムゲーム（`rhythm.html`）に移動します。ゲームの「🎹 ピアノ に もどる」で帰ってこられます
- 🔒 ボタン：ほかのボタンをロック（子どもが設定を触っても変わらない）
- ⛶ ボタン：全画面（iPhone の Safari は全画面 API 非対応なので、その場合は自動で非表示）
- 鍵盤の左下に小さくバージョン番号（`v18` など）をグレーのチップで表示。ここが変わっていなければ、
  ブラウザがキャッシュした古いファイルを開いています
- 設定は端末に保存されるので、次に開いたときも同じ状態
- スクロールは完全に禁止（`position:fixed` ＋ `touch-action:none` ＋ `touchmove` の
  `preventDefault`）。指が2本触れてもページが動きません。ピンチズーム・ダブルタップ拡大も無効

## リズムゲーム「リズムで ポン！」（`rhythm.html`）

リズム天国みたいに、**音楽に合わせて画面をポンと押すと、キャラクターがアクションする**ゲームです。
ピアノと同じくHTML 1ファイルだけ（約40KB）。音楽も効果音もその場で合成しているので、
音源ファイルもライブラリもネット接続もいりません。**押す場所はどこでもOK**（画面全体がボタン）なので、
小さい子でも遊べます。

### 遊びかた

- **ポンポン系（3曲）**：右から飛んでくるボール・ほし・りんご・おにぎりが、キャラクターの前の
  点線の輪に届いた**ちょうどそのとき**に画面をポン！ うまく当たるとパンチしてはじけます。
  - `ばっちり！` ぴったり／`いいね！` ちょっとずれた／`ミス` はずした
  - 連続で当てると「◯れんぞく！」が出て点数が増えます
- **まねっこ**：むらさきの先生が1小節たたいたリズムを、次の1小節でそのまま**まねして**たたきます。
  8問。下のランプが「いま何拍目か」を教えてくれます
- 最後に **★★★ / ★★☆ / ★☆☆** で判定。最高点は端末に保存されます

### 収録曲（ぜんぶオリジナル。その場で合成しています）

| きょく | はやさ | ないよう |
| --- | --- | --- |
| ポンポン たいそう（やさしい） | 92 | ほとんど1拍目と3拍目だけ。はじめて向け |
| はやおし マーチ（ふつう） | 116 | ウラ拍（8分音符）が混ざります |
| おまつり ドンドン（むずかしい） | 134 | シンコペーションだらけ。太鼓の音 |
| まねして ポン（まねっこ） | 104 | 呼びかけ→まねっこ を8回 |

### こまかいところ

- **画面の向きは気にしなくてOK**：ピアノと同じで、iPad が縦向き（回転ロック中）でも
  中身を90°左に回して表示します。**本体を時計回りに倒せば**そのまま横向きで遊べます
- **判定はオーディオ時計（AudioContext）基準**。画面のカクつきに引きずられません
- 音のズレが気になるときは、メニューの「おとの ずれ」で **±10ms ずつ調整**できます
  （Bluetooth スピーカーなどで音が遅れる場合用。端末に保存されます）
- 判定の幅は曲の速さに合わせて自動で変わります（速い曲ほどシビア）
- パソコンではスペースキー / Enter でも押せます

## iPad で開く方法

### 方法1：GitHub Pages で公開する（URL で開く・いちばん手軽）

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** をこのブランチ（`claude/free-game-octave-expansion-unydqu`）、フォルダは `/ (root)` にして Save
3. 1〜2分待つと `https://ttroes6mv.github.io/open/` で公開されます
   （リズムゲームは `https://ttroes6mv.github.io/open/rhythm.html`）
4. iPad の Safari でそのURLを開く → 共有ボタン → **「ホーム画面に追加」**

   ホーム画面から起動すると Safari のバーが消えて、アプリのように全画面で使えます。

### 方法2：ファイルを iPad に入れて開く（インターネット不要）

`index.html`（とリズムゲームで遊ぶなら `rhythm.html` も。同じフォルダに置いてください）を
AirDrop / メール / iCloud Drive などで iPad に送り、
**ファイル**アプリで長押し → 共有 → **Safari で開く**。
オフラインでもそのまま動きます（機内モードでもOK）。

### 方法3：パソコンから同じ Wi-Fi で見る

パソコンでこのフォルダに入って、

```sh
npx http-server -p 8080     # または python3 -m http.server 8080
```

iPad の Safari で `http://<パソコンのIPアドレス>:8080/` を開きます。

## 音が出ないとき

iPad は「画面を1回タッチするまで音を鳴らさない」ルールがあります。鍵盤を1回タップすれば鳴り始めます。
それでも鳴らないときは、本体側面の **消音スイッチ** と音量、Safari の設定を確認してください。
