# どれみピアノ（2オクターブ版）

iPad の Safari でそのまま遊べる、ひらがなラベル付きのタッチピアノです。
**iPad の横画面を前提**にしたレイアウトで、操作ボタンは画面の上端にまとめてあります
（下の広い部分はすべて鍵盤なので、遊んでいる最中に設定を触ってしまいません）。
HTML 1ファイルだけ（`index.html`）でできていて、音源ファイルもライブラリも使いません（Web Audio API で音を合成）。

## できること

- **2オクターブ**（ど〜ど〜ど、白鍵15個）がデフォルト。ボタンで **1 / 2 / 3 オクターブ** に切り替え
- 「◀ ひくい / たかい ▶」で音域そのものを上下に移動（C1〜C8 の範囲）
- 白鍵は **ひらがな（ど れ み ふぁ そ ら し）+ にこにこ顔**、色は元のアプリと同じ配色。
  高いオクターブほど少し明るい色＋白いふちどりで見分けやすくしています
- 黒鍵あり（♯の音も鳴ります）
- 指を何本置いても同時に鳴ります（和音OK）。なぞるとグリッサンド
- がっき4種類：ピアノ / オルガン / ベル / マリンバ
- 音は `PeriodicWave` で倍音を40本まで持たせ、低・中・高の3帯域に分けて別々の速さで減衰させる方式。
  高い倍音が足りずにこもることがなく、エイリアスノイズも出ません。
  ピアノはユニゾンのうなりと高次倍音のうわずり、ハンマーの打撃音を再現。
  仕上げに EQ（110Hz以下カット／300Hz を -4.5dB／3kHz以上を +5dB）と軽いリバーブを通しています
- なまえ表示：ひらがな / ABC（C4 など）/ なし
- 🔒 ボタン：下のボタン類をロック（子どもが設定を触っても変わらない）
- ⛶ ボタン：全画面
- 設定は端末に保存されるので、次に開いたときも同じ状態
- ページのスクロール・ピンチズーム・ダブルタップ拡大は無効化済み

## iPad で開く方法

### 方法1：GitHub Pages で公開する（URL で開く・いちばん手軽）

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** をこのブランチ（`claude/free-game-octave-expansion-unydqu`）、フォルダは `/ (root)` にして Save
3. 1〜2分待つと `https://ttroes6mv.github.io/open/` で公開されます
4. iPad の Safari でそのURLを開く → 共有ボタン → **「ホーム画面に追加」**

   ホーム画面から起動すると Safari のバーが消えて、アプリのように全画面で使えます。

### 方法2：ファイルを iPad に入れて開く（インターネット不要）

`index.html` を AirDrop / メール / iCloud Drive などで iPad に送り、
**ファイル**アプリで長押し → 共有 → **Safari で開く**。
オフラインでもそのまま動きます（機内モードでもOK）。

### 方法3：パソコンから同じ Wi-Fi で見る

パソコンでこのフォルダに入って、

```sh
npx http-server -p 8080     # または python3 -m http.server 8080
```

iPad の Safari で `http://<パソコンのIPアドレス>:8080/` を開きます。

## 音が出ないとき

iPad は「画面を1回タッチするまで音を鳴らさない」ルールがあります。鍵盤を1回タップすれば鳴り始めます。
それでも鳴らないときは、本体側面の **消音スイッチ** と音量、Safari の設定を確認してください。
